# Cit-a — simulateur divin (Godot 4, GDScript)

Façonnez une planète sphérique, créez le couple fondateur de votre peuple, puis regardez des civilisations
autonomes grandir, se convertir, se faire la guerre et passer de l'épée et de la magie à un futur magie + technologie.
2 naissances sur 3 attendent votre décision : Magie, Épée, ou les deux, que seul un dieu peut conférer.
